# Laratter（コメント機能追加版）

受講番号：6th-41

## 1. プロダクトの紹介

講義で作成した SNS アプリケーション「Laratter」に，**Tweetの並び替え機能、いいねの表示をハートの形に変更した**を追加しました．

- Tweetを新着順で表示できる
- Tweetをいいねが多い順で表示できる
- いいね済みの場合は赤いハート、まだいいねしていない場合は白いハートになる

並び替え機能を選んだ理由は投稿を見つけやすくしたかったから。そして今自分が理解できる範囲で作りたかったから。

## 2. こだわった点・苦労した点

- 新着順といいねが多い順を選択できるようにした
- いいね数が多いTweetが上から表示されるようにした
- 苦労した点はハートの形を変えるときにshow.blade.phpだけ変えたらマイページや検索のページは変わっていなかったのでどこのファイルを変えたら解決できるのかわからなかったとこ

## 3. 操作方法

1. トップページから「ログイン」または「新規登録」を行う
2. 「Tweet 一覧」を開く
3. いいねが多い順を選択する
4. いいね数の多いTweetから表示されることを確認する
5. Tweetの♡を押して赤くなることを確認する
